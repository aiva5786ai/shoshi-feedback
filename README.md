## איך שושי עובדת עם זה

- **כל שבוע:** בטאב "השיעור" — לוחצת "שיעור חדש", זה מעתיק את כל השאלות וההגדרות מהשיעור הקודם. משנה רק מה שרוצה. הקישור לתלמידים לא משתנה אף פעם.
- שלושה סוגי שאלות: **טקסט חופשי**, **בחירת אימוג'י** (המערכת מגרילה 3 אימוג'ים חדשים כל שיעור אוטומטית — התלמיד בוחר אחד ומסביר), ו**פתיחים לבחירה** (התלמיד בוחר פתיח כמו "קשור לרגשות שלי" והוא נכנס לתחילת התשובה). התלמידים עונים רק על מה שמדבר אליהם — תשובה אחת מספיקה.
- "הקרנה" — מסך מלא לכיתה, מתעדכן לבד כל 8 שניות.

## שלב ב' — תמונות AI (פעיל מ-2.11.2026)

- כל תלמיד מקבל **תמונת AI אישית** וגם **כרטיס מעוצב** (canvas, חינם). אם התמונה נכשלת, הכרטיס נשאר.
- הקוד: `supabase/functions/shoshi-image/index.ts` (Edge Function). המפתח של שושי שמור רק בסוד `SHOSHI_OPENAI_KEY` ב-Supabase → Edge Functions → Secrets. **לעולם לא** ב-config.js או בטבלה.
- הדפדפן שולח `response_id` ומקבל סטטוס; היצירה רצה ברקע והדפדפן שואל שוב עד שמוכן. עומס של כיתה שלמה: OpenAI מחזיר 429, הפונקציה מחכה ומנסה שוב.
- הגנה על הקרדיט: תמונה אחת לתגובה, נעילה נגד כפילויות, תקרה של 150 תמונות ביממה (`DAILY_CAP`). "תמונה חדשה" מדף הניהול בלבד.
- שושי מדליקה/מכבה לכל שיעור בטאב "השיעור". בטאב "תגובות": "יצירת התמונות החסרות" ו"תמונה חדשה".
- שינוי קוד בפונקציה: Supabase → Edge Functions → shoshi-image → Code → Deploy (אין CLI במחשב).
- עלות: כ-20 אג' לתמונה לכל היותר (gpt-image-2.5-flare, medium, 1024x1536). האחסון: דלי `shoshi-images`, JPEG דחוס; מכסת ה-Free היא 1GB.

## הערות

- זיהוי תלמיד: בלי סיסמאות (שושי ביקשה קל) — נשמר בדפדפן, ובנוסף זיהוי לפי שם: תלמיד שכותב את אותו שם (שם פרטי + משפחה, או שם עם ספרות) מזוהה מכל מכשיר ומקבל אישור "מצאנו אותך — זה את/ה?".
- תלמיד ששולח שוב באותו שיעור — מעדכן את התשובות הקודמות, לא נוצר כפול.
- התגובות נשמרות בנפרד לכל שיעור (lesson_id), ובטאב "תגובות" יש הורדת קובץ אקסל (CSV) נפרד לכל שיעור.
