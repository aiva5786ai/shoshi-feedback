# מערכת פידבק לשיעורים — שושי קוט 💜

שני דפים:
- **index.html** — לתלמידים: נרשמים פעם אחת (שם + תמונה), עונים על השאלות, מקבלים כרטיס אישי מעוצב להורדה.
- **admin.html** — לשושי: עריכת שאלות ופרומפט, קריאת תגובות, מצב הקרנה (שמות / תשובות / תמונות), הגדרות. קוד כניסה התחלתי: **770**.

## חיבור (5 דקות, חד-פעמי)

1. **Supabase** — נכנסים ל-supabase.com → New project (חינם).
2. **SQL Editor** → New query → מדביקים את כל התוכן של `setup.sql` → Run.
3. **Settings → API** → מעתיקים את ה-URL ואת ה-anon key לתוך `config.js`.
4. **העלאה** — מעלים את 3 הקבצים (index.html, admin.html, config.js) לכל אחסון סטטי — Netlify Drop / GitHub Pages / האחסון הקיים.
5. שולחים לשושי שני קישורים: `.../index.html` לתלמידים (זה מה שהיא מפיצה), `.../admin.html` לניהול.

## איך שושי עובדת עם זה

- **כל שבוע:** בטאב "השיעור" — לוחצת "שיעור חדש", זה מעתיק את כל השאלות וההגדרות מהשיעור הקודם. משנה רק מה שרוצה. הקישור לתלמידים לא משתנה אף פעם.
- שלושה סוגי שאלות: **טקסט חופשי**, **בחירת אימוג'י** (המערכת מגרילה 3 אימוג'ים חדשים כל שיעור אוטומטית — התלמיד בוחר אחד ומסביר), ו**פתיחים לבחירה** (התלמיד בוחר פתיח כמו "קשור לרגשות שלי" והוא נכנס לתחילת התשובה). התלמידים עונים רק על מה שמדבר אליהם — תשובה אחת מספיקה.
- "הקרנה" — מסך מלא לכיתה, מתעדכן לבד כל 8 שניות.

## שלב ב' — תמונות AI (כשיגיע האשראי של שושי)

- כרגע התלמידים מקבלים **כרטיס מעוצב** (canvas, חינם) עם התשובות שלהם + הנקודה המרכזית.
- כשיהיה מפתח OpenAI: **לא** לשים אותו ב-config.js או בטבלה שנקראת מהדפדפן — התלמידים יוכלו לחלץ אותו. לחבר דרך Supabase Edge Function שמחזיקה את המפתח בצד השרת. השדות `image_prompt`, `image_style` ו-`responses.image_url` כבר מוכנים לזה, ומצב "תמונות" בהקרנה כבר יודע להציג אותן.
- עלות משוערת: ~20 אג' לתמונה לתלמיד לשיעור (כפי שסוכם עם שושי).

## הערות

- זיהוי תלמיד: בלי סיסמאות (שושי ביקשה קל) — נשמר בדפדפן של התלמיד. אם מחליפים מכשיר נרשמים שוב.
- תלמיד ששולח שוב באותו שיעור — מעדכן את התשובות הקודמות, לא נוצר כפול.
